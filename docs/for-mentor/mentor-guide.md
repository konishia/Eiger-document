# メンター向けガイド：選考プログラム運用手順

長期インターン選考プログラムにおける、学生への案内〜終了後にメンターが行うことをまとめたチェックリスト。学生向け資料は `docs/selection-program-guide.pdf`（選考プログラムの案内）・`docs/assignment-brief.pdf`（課題内容）・`docs/repository-setup-guide.pdf`（リポジトリ準備手順）を参照。

## 1. 選考案内

ゴール：学生に選考案内資料を送り、GitHub アカウント名とメールアドレスを受け取って選考用 Slack チャンネルへ招待する。

- [ ] `docs/selection-program-guide.pdf` / `docs/assignment-brief.pdf` を学生へ送付
- [ ] 学生から GitHub アカウント名・Slack 登録用メールアドレスを受け取る
- [ ] 受け取ったメールアドレス宛に選考用 Slack チャンネルへ招待

## 2. 選考参加時（実装期間に入る前）

ゴール：学生が課題実装を始められる状態にする。

- [ ] `docs/repository-setup-guide.pdf` を共有し、リポジトリ準備を進めてもらう
- [ ] Claude Code のAPIキーをインターンワークスペースから５０ドル分発行してもらう
- [ ] 選考期間中、週1回リモートで繋ぐ日をメンターのシフトに合わせて決める

## 3. 課題提出時

ゴール：面談（発表会）の日程を決める。

- [ ] 学生から最終的な GitHub リポジトリ URL を受領
- [ ] 学生ごとに面談（発表会）の日程を調整
- [ ] 発表内容（工夫点等）をヒアリングし、以下の評価指標に沿ってメモを残す
  - **顧客志向**：現場スタッフ・サポートチームの負担を理解し、減らす設計・実装ができているか
  - **技術的な工夫点**：実装方法・技術選定について自分なりの考え・軸が見えるか
  - **報連相**：曖昧な部分や詰まった点を早めに質問・相談・共有できていたか
- [ ] メンター間で評価指標に基づき合否をすり合わせ、判定結果を確定

## 4. 選考終了後

- [ ] 学生へ合否結果を連絡
- [ ] 経理処理（報酬支払い等）を実施
- [ ] 選考用 Slack チャンネルのアカウントを削除
- [ ] Claude Code のアカウントを削除
