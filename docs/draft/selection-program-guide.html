長期インターン選考プログラムのご案内

長期インターン選考プログラムとは

選考プログラムでは別途案内するデモシステムの開発に取り組んでいただき、そのアウトプットやプロセス・姿勢により長期インターン参加の合否を判定します。

なお、本選考プログラムには3万円の報酬が発生します。

課題：デモシステム開発

別紙にて詳細を案内します

報酬支給には以下の条件を満たす必要があります。

  • 指定する要件を満たすデモシステムのソースコードを自分の GitHub でリポジトリ作成して共有すること

提出方法：GitHub リポジトリを作成し、リポジトリ URL をインターン担当者へ共有してください。（URL共有時リポジトリへインターン担当者を招待してください）

※選考プログラムをスムーズに進めていただくためのサポートツールとして教材や AI ツールを支給します。

選考プログラムの実施概要

期間 参加開始日から1ヶ月間
場所 リモート
稼働時間 期間内で目安20時間（週に1回リモートで出勤してもらう想定。進捗や相談の確認を行う。※ 相談は出勤日でなくても可能です）
報酬 3万円

今後のスケジュール

  1. 本ドキュメントの配布　＜配布時点で選考プログラム参加開始＞
  2. 課題フェーズ：デモシステムの開発　＜参加開始から1ヶ月間＞
  3. 課題となるデモシステムの提出（GitHub）　＜課題フェーズ終了まで＞
  4. デモシステムの工夫点等の完成発表会（個別）　＜課題フェーズ終盤で個別に調整＞
  5. インターン採用判定・合否連絡　＜課題フェーズ終了後、速やかに＞
  6. 選考プログラム終了　＜課題フェーズ終了時＞

ご参加にあたってのお願い

選考プログラムにご参加いただく場合は、以下の情報をインターン担当者へ共有してください。

  • Slack登録用のメールアドレス
  • GitHubアカウントを作成の上、そのアカウント名

最後に

本インターンでは、「学習」ではなく実際のプロダクト・価値創出に向き合う経験を重視しています。本気で技術力を高めたい方、AI・プロダクト開発の現場に踏み込みたい方のご応募をお待ちしています。
