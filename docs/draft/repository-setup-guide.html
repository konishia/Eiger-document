テンプレートを自分のGitHubリポジトリにする手順

長期インターン選考プログラム デモシステム開発課題 ／ このガイドはリポジトリのREADMEを開く前、ZIPファイルを受け取った直後に行う

0. あらかじめインストールするツール

Gitの設定やZIP展開に入る前に、以下を用意する。

  • エディタはVS Codeを推奨。使い慣れたエディタがあればそちらでも構わない（DevContainerでの起動に対応していること）
  • Windowsの場合、この後インストールするDocker DesktopはバックグラウンドでWSL2（Windows Subsystem for Linux）を利用する。インストール時にWSL2のセットアップを求められたら案内に従う（詳細: Docker DesktopのWSL2バックエンド）
  • AIコーディング支援はClaude Codeを、弊社発行のAPIキー経由で使用する（手順は下記）
  • 課題内のAI機能（問い合わせへの一次回答など）を実装する際は、Gemini APIの無料枠などを利用する（追加コストなく実装できる）

Claude Code（弊社発行APIキー）のセットアップ

個人のClaude有料プランへのログインは不要。インターン担当者から共有するAPIキーを環境変数に設定して使う。

  1. Claude Codeをインストールする（公式手順: Quickstart）

    macOS / Linux / WSL:

    curl -fsSL https://claude.ai/install.sh | bash

    Windows（PowerShell）:

    irm https://claude.ai/install.ps1 | iex

    インストール後、ターミナルを開き直して確認する。

    claude --version
  2. インターン担当者からAPIキーを受け取る

    選考プログラム参加後、担当者からAPIキー（sk-ant-... 形式）が共有される。自分でClaude Consoleから発行する必要はない。

  3. 環境変数 ANTHROPIC_API_KEY に設定する

    以下のコマンドの 共有されたAPIキー を実際の値に置き換えて実行する。

    macOS（zsh）:

    echo 'export ANTHROPIC_API_KEY="共有されたAPIキー"' >> ~/.zshrc
source ~/.zshrc

    Linux / WSL（bash）:

    echo 'export ANTHROPIC_API_KEY="共有されたAPIキー"' >> ~/.bashrc
source ~/.bashrc

    Windowsの場合は「システムのプロパティ」→「環境変数」→ユーザー環境変数に新規追加する。

    • 変数名: ANTHROPIC_API_KEY
    • 変数値: 共有されたAPIキー

    設定後はターミナル（またはPowerShell）を開き直す。

  4. 動作確認する

    キーの値は表示せず、設定されていることだけを確認する。

    macOS / Linux / WSL:

    [ -n "$ANTHROPIC_API_KEY" ] && echo "ANTHROPIC_API_KEY is set" || echo "ANTHROPIC_API_KEY is not set"

    Windows（PowerShell）:

    if ($env:ANTHROPIC_API_KEY) { 'ANTHROPIC_API_KEY is set' } else { 'ANTHROPIC_API_KEY is not set' }

    その後 claude を起動する。キーが設定されていれば、個人アカウントへのログインを求められず、APIキー利用の確認が出る。対話内で /status を実行し、認証方式がAPIキーになっていることを確認する。

注意
  • APIキーは第三者に見せない・GitHubにコミットしない（チャット・スクショへの貼り付けも避ける）
  • 個人のClaude Pro / Maxプランでログインしない。必ず弊社発行のAPIキー（環境変数）を使う
  • キーが届いていない・動かない場合はインターン担当者へ連絡する
ゴール: claude --version が表示され、ANTHROPIC_API_KEY が設定された状態で claude が起動できる。

1. 事前に用意するもの

  • Git（Windowsの場合、インストール時に一緒に入る「Git Bash」をターミナルとして使うのがおすすめ）
  • GitHubアカウント（すでに持っていればそれを使う）
ゴール: ターミナルで git --version を実行してバージョンが表示される。かつGitHubに自分のアカウントでログインできる。

2. ZIPファイルを展開する

受け取ったZIPファイルをダブルクリックして展開し、わかりやすい場所（デスクトップなど）に置く。

3. 自分のGitリポジトリとして初期化する

展開したフォルダをターミナルで開き、以下を実行する。

cd <展開したフォルダ>
git init
git add -A
git commit -m "chore: initial commit"
初めてGitを使う場合は、git commitの前に一度だけ以下を実行して自分の名前とメールアドレスを設定しておく。
git config --global user.name "自分の名前"
git config --global user.email "自分のメールアドレス"

4. GitHubで新しいリポジトリを作成する

  1. github.com/new を開く
  2. Repository name を入力する（例: my-intern-assignment）
  3. Public を指定すること
  4. README・.gitignore・ライセンスは追加しない（チェックを入れない）。追加すると、次の手順のpushで履歴がぶつかってしまう
  5. 「Create repository」を押す

5. 作成したリポジトリにpushする

作成後の画面に表示されるリポジトリのURL（https://github.com/自分のアカウント名/リポジトリ名.git）を使い、ターミナルで以下を実行する。

git remote add origin <作成したリポジトリのURL>
git branch -M main
git push -u origin main
初回push時にログインを求められることがある。GitHubはパスワードでの認証を廃止しているため、以下のどちらかで認証する。
  • Personal Access Tokenを作成し、パスワード欄に貼り付ける
  • GitHub CLIをインストールし、gh auth loginでブラウザ経由で認証する（迷ったらこちらがおすすめ）
ゴール: 自分のGitHubアカウント上に、このテンプレートの中身が入ったリポジトリができている。ブラウザでそのリポジトリを開き、ファイル一覧と README.md が表示されればOK。

次にやること

ここまで完了したら、GitHub上の自分のリポジトリを開き、README.mdの案内に沿ってローカル環境を起動する（Docker Desktopのインストール、DevContainerでの起動）。
